## Implemented boundary and exactness

Enable with `NEWTON_NARROW_PHASE_CONVEX_BSP=1`. Admission is geometric, not task-named: a finite, closed, convex, all-extreme triangulated hull with 4–256 stored vertices, exact two-limb plane coefficients of at most 106 bits, and a bounded tree (10,000 nodes, depth 40). Unsupported hulls use the original support callback; unsupported pipeline families never construct an owner. KukaAllegro's shared hand hulls are covered by the same provider, subject to its actual pipeline admission. No Kuka performance or physics result is claimed.

The existing query preparation resolves each endpoint's mesh pointer once per MPR, GJK or manifold kernel invocation into a private root index. Every support query then performs only tree traversal and one winning vertex read; no per-query pointer search, per-world support cache, added maximum panel, new recurring kernel, or recurring allocation is introduced. The ordinary and coherent source successors append one static descriptor argument; stripping these substitutions recovers the original factory ASTs exactly. The ordinary primitive calculation and contact postprocessor are called through type-only adapters. The coherent rejection classifier and its full-scan feature producer are unchanged and remain charged.

Plane signs use explicit RN FP32 arithmetic with a conservative `16*eps32` work bound and `64*FLT_MIN` absolute underflow allowance, then explicit RN FP64 with `16*eps64` work bound. These bounds include the exact plane's stored coefficient conversion error. Admitted nonzero plane coefficients are at least `2^-106`; finite FP32 directions keep every exact-tier product within the normal FP64 exponent range. Final ambiguity uses six FMA TwoProducts and zero-eliminating GrowExpansion/TwoSum, returning the sign of the exact sum, including a genuinely computed zero. No ambiguous sign is guessed and no approximate hull replaces the stored geometry. Nonfinite query direction returns to the original support callback.

Mutation is deliberately explicit: `CollisionPipeline.invalidate_convex_bsp()` clears the graph-visible valid flag and the existing coherent rejection cache before an owner edits/refits mesh points. It must run outside capture and be ordered before writes on every participating stream. Existing arrays are never reactivated or replaced. A new pipeline and recapture are required to regain BSP after an edit. A caller that mutates points without notification is unsupported; pointer identity is not asserted to detect such mutation. Existing model/pipeline lifetime obligations remain in force for captured graphs.

## CPU qualification so far (not CUDA acceptance)

Missing-native regression first failed with `ModuleNotFoundError`; exact-sign compilation then exposed and fixed only a Warp cast-macro mismatch. Complete factory compilation exposed two typed primitive/postprocessor seams; adapters now retain their original arithmetic.

Final expanded CPU command ran 27 tests in 24.880 s: 25 passed and two pre-existing CUDA-only tests skipped. All nine BSP tests ran, including explicit actual asset and historical corpus. It checked 11,394 directions on all ten actual cooked hulls plus 104,892 historical CPU query directions against exact integer geometric support, with zero support deficit. Historical source weighting is not current post-rejection GPU weighting. Changed native full-scan winners were 438 RTX-corpus / 478 GB-corpus; 23/22 were exact geometric ties and 415/456 were strict geometric improvements. Changed indices are retained as evidence, not treated as physical failure or a performance win. Controlled complete ordinary lean/full and coherent MPR/GJK/manifold paths passed analytic depth, normal and contact-position gates, and invalidation followed by a mesh edit matched the original callback. BOX/SPHERE centered ties were exact. The CUDA variant additionally captures and replays the invalidated provider, but has not run yet.

Actual static descriptor size is 75,784 bytes for the ten unique hulls (eight 64-vertex, two 40-vertex). Max tree depth is 9/6. This includes exact high/low coefficients, node children/plane IDs, mesh lookup/roots and the validity flag; it is not multiplied by world count.
