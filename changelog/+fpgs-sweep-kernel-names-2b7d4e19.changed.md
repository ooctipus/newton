Rename the sweep kernels that `SolverFeatherPGS` reports in `get_path_selection()["routes"]["sweep"]` from `pgs_solve_*` to `sweep_*` (for example `sweep_mf_gs_*`, `sweep_sparse_*`, `sweep_tiled_row_*`, `sweep_mf_split_*`, `sweep_loop`): every sweep is now generated by one emitter. Kernel names drop operands that the sweeps never read, such as the loop sweep's row capacity.
