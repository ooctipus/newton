Add the experimental `NEWTON_TERRAIN_LAW_SHADOW_JOBS` environment variable, a factor on the job lists and candidate pools of the solid classes (`box`, `cylinder`, `hull`) in the `NEWTON_TERRAIN_LAW_SHADOW` side buffer. These classes now run as the heightfield route does instead of one thread walking each pair's window: a scan lists the window features that pass their cheapest rejects, one thread per listed feature evaluates its rule, and a close per pair takes the rows in window order, so every pair's rows stay the same bit for bit. The lists are sized once from the pairs' own bounds (default factor 1); a pair whose work finds no room is walked again by its class's full-finish kernel, and the job check prints the entries asked for against the room.
