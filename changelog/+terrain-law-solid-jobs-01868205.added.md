Add the experimental `NEWTON_TERRAIN_LAW_SHADOW_JOBS` environment variable, a factor on the job lists and candidate pools of the solid classes (`box`, `cylinder`, `hull`) in the `NEWTON_TERRAIN_LAW_SHADOW` side buffer. These classes now run as the heightfield route does instead of one thread walking each pair's window: a scan lists the window features that pass their cheapest rejects, one thread per listed feature evaluates its rule, and a close per pair takes the rows in window order, so every pair's rows stay the same bit for bit. The lists are sized once from the pairs' own bounds (default factor 1), each with a fixed reserve beyond that room: work that finds no room takes the reserve with its pair's rows unchanged, raises the `terrain_jobs` buffer status, and the job check prints the entries asked for against the room by class and list; a pair whose work finds no room in the reserve either keeps no row. The solid classes' shadow launches need a CUDA 12.1 or newer driver.
