Warn about and ignore an explicit `pgs_kernel` in `SolverFeatherPGS` matrix-free mode instead of raising `ValueError`; matrix-free mode owns its sweep kernels. With `friction_anchor_beta` given, the solver equals the one built with `pgs_kernel="auto"`. With `friction_anchor_beta` omitted, an ignored `tiled_contact` or `streaming` request still selects velocity-only point friction, as it did before such requests raised, and the warning and `get_path_selection()` say so. Omit `pgs_kernel` (or use `pgs_mode="split"`) to silence the warning, and also pass `friction_anchor_beta=0` to keep point friction; an explicit `delassus_kernel` in matrix-free mode still raises.
