Stop recognizing retired `FEATHER_PGS_*` environment variables in `SolverFeatherPGS`: a removed switch is an undeclared name like any other, listed under `get_path_selection()["environment"]["unknown"]`. The retired selectors that raised when set to 1 (`FEATHER_PGS_SINGLE_FACTOR`, `FEATHER_PGS_BODY_BASIS_ROWS`, `FEATHER_PGS_SPARSE_PACKETS`, `FEATHER_PGS_SPARSE_PAIRED_GS`, `FEATHER_PGS_COUPLED_CONTACT`, `FEATHER_PGS_COUPLED_JACOBI`, `FEATHER_PGS_DENSE_ROW_REGISTERS`) no longer raise, the solver no longer warns about retired names, and the solver's `environment["retired"]` stays empty. Unset the variables.
