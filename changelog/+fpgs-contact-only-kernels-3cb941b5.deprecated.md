Deprecate `SolverFeatherPGS(pgs_kernel="tiled_contact")`, `pgs_kernel="streaming"` and the `pgs_chunk_size` parameter that tuned the streaming kernel; the two contact-only split-mode kernels were removed. These values now warn, have no effect and will be removed in a future release: either kernel name selects the `"auto"` kernel (`"tiled_row"` on CUDA, `"loop"` on CPU) with the default patch friction, also with joint limits. Omit `pgs_kernel` and `pgs_chunk_size`, and pass `friction_anchor_beta=0` to keep velocity-only point friction.
