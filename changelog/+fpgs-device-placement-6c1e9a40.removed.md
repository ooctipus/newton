Remove `SolverFeatherPGS(pgs_mode=...)`: the device chooses the formulation. CUDA solves every model matrix-free, and the CPU assembles the Delassus rows and sweeps them one thread per world, as `pgs_mode="split"` did there. Split mode's CUDA sweeps (the tiled-row Delassus sweep, the native free-body split sweep and the native sparse factors' split sweep) and the CUDA Delassus kernels go with it; `solver.pgs_mode` is gone.
