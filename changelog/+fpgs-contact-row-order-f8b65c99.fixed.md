Make `SolverFeatherPGS` repeat its results bit for bit under `CollisionPipeline(deterministic=True)` on CUDA. Each world's contact rows now follow the sorted contacts' order instead of the order in which GPU threads reserve them, so solvers stepping the same contacts solve the same rows; before, runs on identical contacts could build a world's rows in another order, and an unconverged Gauss-Seidel solve then ended elsewhere. The default pipeline keeps the atomic reservation and its cost.
