Repair `SolverFeatherPGS`'s cached dynamics on CUDA over a list of the cache groups that need it, built by a one-thread-per-group classification, when the step reads the state its caches were published into, instead of launching one block per group that mostly confirms its cache; each listed group computes the same values as before. Set `FEATHER_PGS_TREE_REPAIR_CLASSIFY=0` to keep one block per group; `get_path_selection()["routes"]["held_tree"]["groups"][i]["classify_first"]` reports the choice and `["kernels"]` names the comparison, classification and listed repair kernels.
