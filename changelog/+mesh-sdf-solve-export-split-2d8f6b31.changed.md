Split the texture mesh-SDF solve into a search kernel that writes compact hit records and a separate full-occupancy export kernel that reduces them, keeping the hashtable round trips out of the texture-bound edge search. Hit records share the triangle-pair scratch buffer with the edge segments, so ``NarrowPhase.mesh_sdf_segment_capacity`` is now ``3 * max_triangle_pairs // 2050`` instead of ``// 514``; scenes that exceed it fall back to the fused kernel exactly as before. Reduced contact output is unchanged; no migration needed.
