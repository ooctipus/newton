Split the cells of long heightfield pair windows over warp lanes in the CUDA terrain midphase. Pairs with more than 16 cells move from the one-thread-per-pair pass to a second pass with 16 lanes per pair, and each cell appends its surviving triangles with one aggregated reservation. Every cell runs the same tests, so the emitted triangles and raw contacts are identical and only their order changes; CPU runs keep the original order. Set `NEWTON_HEIGHTFIELD_LANE_MIDPHASE=0` before constructing the collision pipeline to keep one thread per pair for every cell.
