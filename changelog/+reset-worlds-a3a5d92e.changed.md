Make `SolverMuJoCo.reset(world_mask)` cost proportional to the number of selected worlds on the MuJoCo Warp path. The mask is compacted on the device into a world id list (no host synchronization), the buffer, coordinate and sleep-state kernels run over that list, and MuJoCo Warp's position- and velocity-dependent data is rebuilt with `mujoco_warp.forward_worlds` for the selected worlds only (models outside MuJoCo Warp's fused per-world path still rebuild every world). Unselected worlds are now left untouched; previously every reset recomputed their derived data. Constraint rows and island partitions of the selected worlds are no longer rebuilt at reset, the next step recomputes them before use.
