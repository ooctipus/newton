Clear only the selected articulations' blocks in masked `newton.eval_jacobian` and `newton.selection.ArticulationView.eval_jacobian` calls instead of the whole padded Jacobian. Selected blocks, padding included, are unchanged; entries of unselected articulations are now left as the caller's buffer held them instead of being zeroed, so call `J.zero_()` first if code reads them. `J=None` still returns zeros for unselected articulations.
