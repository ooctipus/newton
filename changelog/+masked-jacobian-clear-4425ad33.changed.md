Clear only the selected articulations' blocks of a supplied Jacobian in `newton.eval_jacobian` calls with a `mask` and in every `newton.selection.ArticulationView.eval_jacobian` call, with or without `mask`, instead of the whole padded Jacobian, when each block holds at least 1024 entries; smaller Jacobians are still zeroed whole, which is faster for them. Selected blocks, padding included, are unchanged. The blocks of articulations outside the view or the mask are now unspecified: they are either zeroed or left holding the values the buffer held. Call `J.zero_()` first if code reads them. With `J=None` they are still zero.
