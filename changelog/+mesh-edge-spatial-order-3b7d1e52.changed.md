`ModelBuilder.finalize()` orders each mesh's packed collision edges along a Morton curve of their midpoints, so consecutive edges of `Model.mesh_edge_indices` / `mesh_edge_centers` / `mesh_edge_halves` are spatially adjacent and the lanes of a mesh-SDF narrow-phase warp sample neighbouring SDF texels. The edge set per shape is unchanged; code that assumed the packed edges keep the order of `Mesh.edges` or `Mesh._collision_edges` must index through the packed arrays instead.
