Step each friction pair of the `SolverFeatherPGS` parallel tiers that serve persistent patch friction with the smaller of its two tangent steps, so a sliding pair converges to the serial patch sweep's maximal-dissipation fixed point instead of a friction direction turned towards its stiffer tangent. The tiers share the serial sweep's whole fixed point only where both accumulate joint velocity-limit rows (`velocity_limit_law="accumulated"`, or no joint velocity limits), which `routes.friction.parallel_rows` reports. The tier kernels' names gain `_iso`, and `get_path_selection()` reports `routes.sweep.tiers.pair_step`. Point-friction tiers keep per-row steps. No migration is required: point-friction solvers run the same kernels as before, and `FEATHER_PGS_PATCH_PARALLEL_ROWS=0` keeps patch friction off the tiers.
